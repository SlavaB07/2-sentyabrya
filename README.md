Мини-графический редактор
1. Название и описание задачи

Мини-графический редактор** — это программа, которая демонстрирует основные принципы объектно-ориентированного программирования (ООП) на примере работы с геометрическими фигурами.

Программа позволяет:
- Создавать фигуры (круги и квадраты)
- Вычислять их площадь
- Работать с фигурами единообразно, независимо от их типа

Задача решает проблему организации кода при работе с разными типами фигур, используя три основных принципа ООП: инкапсуляцию, наследование и полиморфизм.

2. Архитектура проекта
2.1. Инкапсуляция

В программе реализована инкапсуляция через сокрытие данных:

| Класс | Скрытые данные (приватные) | Публичные методы |
|-------|---------------------------|------------------|
| `Figure` | `__x`, `__y` (координаты) | `get_coords()`, `set_coords()` |

Координаты фигур защищены от прямого изменения извне. Доступ к ним возможен только через специальные методы-геттеры и сеттеры.

2.2. Наследование
Схема наследования:
Figure (базовый класс)
/
/
Circle Square

- **`Figure`** — базовый класс, содержит общие для всех фигур данные (координаты)
- **`Circle`** — дочерний класс, добавляет свойство `radius` (радиус)
- **`Square`** — дочерний класс, добавляет свойство `side` (сторона)

Дочерние классы наследуют все методы и атрибуты родительского класса, что позволяет избежать дублирования кода (принцип DRY).

2.3. Полиморфизм

Полиморфизм реализован через единый интерфейс:
- Все дочерние классы (`Circle`, `Square`) имеют метод `calculate_area()`
- В главной программе мы создаём список фигур разных типов и в **одном цикле** вызываем `calculate_area()` для каждой фигуры
- При этом мы не знаем точный тип фигуры, но благодаря полиморфизму выполняется правильная реализация метода для каждого типа

3. Пример использования

```python
circle1 = Circle(0, 0, 3)      # круг с радиусом 3
square1 = Square(1, 2, 4)      # квадрат со стороной 4
circle2 = Circle(3, 4, 2.5)    # круг с радиусом 2.5

print(circle1.get_coords())     # (0, 0)

print(circle1.calculate_area()) # 28.27431
print(square1.calculate_area()) # 16

shapes = [circle1, square1, circle2]
total = 0
for shape in shapes:
    total += shape.calculate_area()
print(f"Общая площадь: {total:.2f}")
