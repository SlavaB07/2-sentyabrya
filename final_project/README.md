# HTTP Client & Server с графическим интерфейсом на Python

Финальный проект 4 курса. Десктопное приложение на Python, состоящее из HTTP-клиента и HTTP-сервера, работающих на голых сокетах (`socket`), с графическим интерфейсом на `tkinter`.

## 🚀 Возможности

### HTTP-клиент
- Поддержка методов **GET** и **POST**.
- Парсинг URL (хост, порт, путь, query).
- Отправка пользовательских заголовков.
- Обработка `Content-Length` и `Transfer-Encoding: chunked`.
- Таймауты соединения и чтения.
- Обработка ошибок (`ConnectionError`, `TimeoutError`, `HttpError`).
- Фоновые запросы (GUI не замерзает).

### HTTP-сервер
- Слушает порт (по умолчанию 8080).
- Многопоточная обработка входящих соединений.
- Маршруты:
  - `GET /echo` — HTML-страница "Hello".
  - `POST /echo` — возвращает тело запроса (эхо).
  - `GET /time` — текущее время в JSON.
  - `GET /headers` — заголовки запроса в JSON.
  - `GET /status/{code}` — ответ с указанным статус-кодом.
  - `*` — 404 Not Found.
- Логирование запросов в GUI.
- Корректная остановка сервера (через закрытие сокета).

### Графический интерфейс
- Вкладка **«Клиент»**: ввод URL, выбор метода, таблица заголовков, поле тела, кнопки «Отправить» и «Очистить», область ответа с подсветкой.
- Вкладка **«Сервер»**: поле порта, кнопки «Запустить»/«Остановить», индикатор состояния, лог запросов, кнопка «Открыть в браузере».

🚦 Запуск
Установка зависимостей (только для тестов)
bash
pip install -r requirements.txt
Запуск приложения
bash
python -m src.main
Запуск тестов
bash
pytest tests/ -v
Ручная проверка сервера
bash
# Запустить сервер через GUI или в фоне:
python -m src.main &

# Затем в другом терминале:
curl -v http://localhost:8080/
curl -v -X POST -d "hello" http://localhost:8080/echo
curl -v http://localhost:8080/status/418
