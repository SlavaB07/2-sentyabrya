Мини-графический редактор

1. Название и описание задачи

Мини-графический редактор — это программа, которая демонстрирует основные принципы объектно-ориентированного программирования (ООП) на примере работы с геометрическими фигурами.

Что делает программа:
- Создаёт геометрические фигуры (круги и квадраты) с заданными координатами и размерами
- Вычисляет площадь каждой фигуры
- Считает общую площадь всех фигур в списке
- Демонстрирует работу трёх основных принципов ООП

Какую задачу решает:
Программа решает проблему организации кода при работе с разными типами фигур. Вместо написания отдельного кода для каждой фигуры, мы используем единую структуру, которая легко расширяется для добавления новых типов фигур без изменения существующего кода.

2. Архитектура проекта

2.1. Инкапсуляция

Инкапсуляция реализована через сокрытие внутренних данных фигур:

| Класс | Скрытые данные (приватные) | Публичные методы |
|-------|---------------------------|------------------|
| `Figure` | `__x`, `__y` (координаты) | `get_coords()` — получить координаты<br>`set_coords()` — изменить координаты |

**Как это работает:**
```python

self.__x = x
self.__y = y

def get_coords(self):
    return (self.__x, self.__y)

def set_coords(self, x, y):
    self.__x = x
    self.__y = y

    2.2. Наследование
Схема наследования классов:


        Figure (базовый класс)
       /      \
      /        \
   Circle    Square
Класс	Тип	Свойства
Figure	Базовый (родительский)	__x, __y — координаты
Circle	Дочерний (наследует Figure)	radius — радиус круга
Square	Дочерний (наследует Figure)	side — сторона квадрата
Преимущества наследования:

Дочерние классы автоматически получают все свойства и методы родителя

Код не дублируется (принцип DRY — Don't Repeat Yourself)

Легко добавлять новые типы фигур

2.3. Полиморфизм
Полиморфизм реализован через единый интерфейс для всех типов фигур:

Единый метод: calculate_area()

В классе Circle — вычисляет площадь круга: π × r²

В классе Square — вычисляет площадь квадрата: a²

Как используется:

shapes = [Circle(...), Square(...), Circle(...)]

for shape in shapes:
    area = shape.calculate_area()  
Главное преимущество: Мы не проверяем тип фигуры. Каждый объект сам "знает", как вычислить свою площадь. При добавлении нового типа фигуры (например, Triangle) старый код не нужно менять!

3. Пример использования

from task9_/task9 import Circle, Square

circle = Circle(0, 0, 3)      
square = Square(1, 2, 4)      

print(circle.get_coords())   

print(circle.calculate_area()) 
print(square.calculate_area()) 

shapes = [
    Circle(0, 0, 3),
    Square(1, 2, 4),
    Circle(3, 4, 2.5)
]

total = 0
for shape in shapes:
    total += shape.calculate_area()
print(f"Общая площадь: {total:.2f}")
